Проверено 1 ноября 2026. Исследование не меняет сетевое поведение установленного приложения.

Встроенный скрипт объявляет `GAS_URL`, загружает весь ответ через `fetch(GAS_URL, {cache: "no-store"})` и разбирает `res.json()`.

Источник:

https://script.google.com/macros/s/AKfycbwW8yTxVGMvsklnIscEP87grbdxHkWv9-Dvztm00rjhM2xeNFqL-HRtnDZuldpfRVtI/exec

Это публичный веб-сервис Google Apps Script. Сайт получает данные из него; поиск по группе выполняется в браузере по тексту уже созданных карточек. Для поиска отдельного серверного запроса нет.

За сервисом, вероятно, Google Таблицы: ответ содержит поля `лист`, `дата`, `данные`. Код Apps Script и ссылка на исходную таблицу в изученном фрагменте страницы не опубликованы, поэтому внутренний источник не подтверждён.

## Проверенный ответ

Два обычных GET-запроса без cookies, входа и API-ключа завершились HTTP 200 и вернули JSON. Ответ содержит шесть дней, по 87 строк групп в каждом. Для ИС-232 найдена ровно одна строка в каждом дне.

Структура дня: `лист` — название дня недели, `дата` — строка `ДД.ММ.ГГГГ` или пустая строка, `данные` — массив строк. В строке есть `Группа`, `1 пара`…`5 пара`, `ауд1`…`ауд5`. В полях пар находятся преимущественно преподаватели или маркер `Нет занятия`, а не названия дисциплин.

На момент проверки даты заполнены только для 30.10.2026, 31.10.2026 и 02.11.2026. Вторник, среда и четверг содержат данные, но не имеют даты. Скрипт сайта не создаёт кнопки для дней с пустой датой. Нельзя приписывать этим данным ближайшую календарную дату по названию дня недели.

Для ИС-232 на **02.11.2026**:

| Пара | Значение источника | Аудитория |
| --- | --- | --- |
| 1 | Нет занятия | Нет |
| 2 | Нет занятия | Нет |
| 3 | Бородина Е.Н. | 106 К1 |
| 4 | Давыдова Е.В. | Тр/З К1 |
| 5 | Нет занятия | Нет |

Для 31.10.2026 все пять аудиторий ИС-232 содержат `ДО`, что согласуется с уточнением пользователя о дистанционной субботе. Ответ за 30.10.2026 содержит пятую пару у Гладких, которой нет в перенесённом постоянном очном расписании на пятницу. Это подтверждает, что источник отличается от базового PDF; полнота и своевременность всех замен этим не гарантируются.

## Правила подключения к приложению

- Получать JSON по HTTPS с обработкой перенаправлений, выбирать точную дату и точное значение `Группа = ИС-232`.
- Без совпавшей даты или строки группы показывать, что актуальных данных нет. Отличать такую ситуацию от опубликованной строки, в которой все пары отменены.
- Пустую дату не использовать как сегодняшнюю; старую пятницу не использовать как следующую пятницу.
- Сохранять кэш и дату полученного расписания, отдельно показывать время последнего успешного получения. В ответе нет явного времени последнего изменения.
- `Нет занятия`, пустые аудитории и `ДО` обрабатывать отдельно. Субботнее ДО не включать в очные пары согласно пожеланию пользователя.
- Не выводить название предмета по одной фамилии: Бородина ведёт несколько дисциплин. Достоверная информация из этого источника — номер пары, преподаватель и аудитория.
- В текущем APK онлайн-загрузка ещё не подключена. Для интеграции нужны разрешение INTERNET, фоновый запрос, разбор/проверка JSON и честная маркировка источника/кэша.

Повторить проверку:

```powershell
python -X utf8 tools/probe_schedule.py --group ИС-232
```

Скрипт только читает публичный источник и выводит строки выбранной группы. Он не меняет сайт или приложение. Признак `published` означает наличие даты, по которому сайт показывает кнопку дня; это не независимая гарантия свежести.
