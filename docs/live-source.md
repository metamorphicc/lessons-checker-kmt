## Страница и источник

Встроенный скрипт объявляет `GAS_URL`, загружает весь ответ через `fetch(GAS_URL, {cache: "no-store"})` и разбирает `res.json()`.

Источник:

https://script.google.com/macros/s/AKfycbwW8yTxVGMvsklnIscEP87grbdxHkWv9-Dvztm00rjhM2xeNFqL-HRtnDZuldpfRVtI/exec

Это публичный веб-сервис Google Apps Script. Сайт получает данные из него; поиск по группе выполняется в браузере по тексту уже созданных карточек. Для поиска отдельного серверного запроса нет.

За сервисом, вероятно, Google Таблицы: ответ содержит поля `лист`, `дата`, `данные`. Код Apps Script и ссылка на исходную таблицу в изученном фрагменте страницы не опубликованы, поэтому внутренний источник не подтверждён.
