# Native UI audit — November 2, 2026

Reviewed version 1.2 at commit `e6f0206` using Hallmark's audit, interaction-state, layout, and contrast checks. Web-only rules about heroes, CSS stamps, browser navigation, and font pairing were not applied to a native Android utility.

## Confirmed findings

1. **Critical / P1 — compact size is not guaranteed.** The Android 16 AOSP launcher offered the widget as **3 × 3** at a 320 dp display width. `app/src/main/res/xml/lessons_widget.xml:2` declares a 110 dp minimum; the 2-cell target cannot override the launcher's minimum span. Lower the minimum after making the content fit, then verify the actual launcher dialog.
2. **Major / P1 — text clips at the supported minimum.** `app/src/main/res/layout/widget.xml:8` gives the title the remaining height. At 110 × 110 dp its text layout needs 31 dp but receives 24 dp; at font scale 1.3 it needs 41 dp but receives 10 dp. Use fewer lines/metadata in compact mode and verify large-font rendering.
3. **Major / P2 — automatic updates reset scrolling.** `MainActivity.java:28` calls `show()` every 30 seconds; `show()` creates a new ScrollView. Instrumentation measured scroll position **290 → 0** and a different view instance after 31 seconds. Preserve the reading position or update existing content.
4. **Major / P2 — settings drafts disappear on recreation.** `MainActivity.java:33` always opens the schedule; `onSaveInstanceState` only saves the selected date and follow flag. After entering **09:00**, recreating the Activity returned to the schedule and discarded the settings screen. Save the editing mode, draft fields, and settings scroll position.
5. **Major / P2 — refresh target is too small.** `widget.xml:6` gives the refresh control 28 × 24 dp. Its glyph layout needs 31 dp vertically. Provide a full-size target in expanded mode; let the compact widget open the app for refresh rather than retaining an undersized control.
6. **Minor / P3 — loading remains actionable.** `MainActivity.java:97` changes the refresh label but leaves the button enabled. Disable it while a request is in progress.

## Checks completed

The emulator is isolated in the ignored `tmp/ui-audit` directory. UI tests use controlled local data, so the empty fixture must not be interpreted as evidence that the college has no published schedule. Physical-device launcher behavior and background delivery still need device-specific verification.

Audit result before fixes: **1 critical · 4 major · 1 minor**.

## Fix verification — version 1.3

The audit phase was completed before implementation. The fixes preserve the existing native Android structure and green palette; no application screens or routes were removed.

- **Launcher span:** the same AOSP launcher pin dialog now reports **2 × 2** after reducing the supported minimum to 90 dp and adapting compact content.
- **Text clipping:** at 90 × 90 dp and font scale 1.3, the title receives 22 dp for a 19 dp text layout. Compact time is shortened to an end/start label such as **До 13:50**, and the classroom is shown as **106 К1** without a redundant prefix; both remain readable. Long names may still be ellipsized horizontally; tapping opens the full app. Compact mode omits refresh/footer rows and includes the source in its status.
- **Scrolling:** after 31 seconds the position remains **290 → 290**, despite replacing the view. Restoration happens after layout and preserves pending positions.
- **Drafts:** after recreating the Activity, the settings screen stays visible and the edited value remains **09:00 → 09:00**. Draft times, zone choice, and scroll position are included in saved state.
- **Touch target:** expanded refresh controls are 48 × 48 dp. Compact mode opens the app through the entire widget instead of presenting the old undersized refresh control.
- **Loading:** native instrumentation reports `refreshEnabled: false` while the request state is active.
- **Build:** 36 calendar checks, 25 live-data/cache tests, release assembly, Android lint, APK signature verification, and installation of the release APK on the emulator pass.
